Comparing Website Development through Github Pages and Wordpress

In this reflection, I will be comparing the process of developing a website using Github Pages and Wordpress. I'll share my honest thoughts, and give you my overall opinion (as a beginner website designer).

Significant Challenges as a New Learner

For someone who wants to casually develop a website, I'd suggest using Wordpress. This suggestion stems mainly from the complexity of using Github Pages. Not only do you have to learn HTML and CSS coding, but you also have to understand how to use the command line for keeping your Github repository up to date. Wordpress really isn't challenging whatsoever; as long as you understand how to navigate the admin controls, you'll be fine.

Advantages of using Github Pages

  • Very customizeable. Personally, I found it a lot easier to customize my website using CSS/HTML coding rather than using Wordpress. Wordpress does allow custom CSS styling, but it isn't compatible with regular CSS coding- Wordpress only understands their language of CSS, if that makes sense.
  • Satisfactory. Using Github Pages to develop websites is hard work, but in my opinion, there was nothing better than seeing all of my hard work come to life.

Advantages of using Wordpress

  • Simple. Wordpress offers simplicity when it comes to developing websites. This is very great for users who want to casually create a simple website.
  • Quick. Developing websites through Wordpress is very fast. All you have to do is make sure you save your changes as you go, and that's it. On the otherhand, it isn't as simple as just saving your changes with Github Pages. After you save the documents you've been working on, you have to push those changes into your Github repository using the command line, wait a couple minutes for those changes to reflect, then your website is good to go. It's not too complicated, but it is a little more time consuming than Wordpress's process.

Overall Thoughts and Opinions

I personally prefer using Github Pages over Wordpress. I believe Github Pages gives the user a lot more freedom with tailoring their website to their needs. Although the process is a lot more hands-on and technical, you can make it anything you want with little to no limitations. I think Github Pages supports the creative mind a lot more than Wordpress does, partially because you have to build it from scratch.

Additionally, Github Pages is really great for allowing users to build their confidence with HTML/CSS coding. As a beginner, I'm sure there's more coding languages that Github may support- which I cannot wait to learn in the future. Github Pages is a great resource for a wide variety of people, ranging from coding experts to beginner web developers.

I'd also like to note- Github Pages may not be the right choice for someone who is not serious about web development, or someone who only needs a simple one-time-use website. That's where Wordpress comes in- Wordpress is the better choice for people who don't plan on developing multiple complex websites. Wordpress offers great solutions rather than manually coding websites- services as simple as choosing theme presets, writing your web pages similar to a Word document, and so much more.

I don't think Github Pages is inherently better than Wordpress- I think it's very dependent on the users' intentions with web development. Personally, Github Pages will be my preference for future projects based on the reasons above.
